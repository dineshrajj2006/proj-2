My project is titled  Movie Analytics Dashboard. The main objective of this project is to analyze movie industry data and gain insights into movie ratings, budgets, revenues, genres, actors, directors, and yearly release trends. I used Python and Pandas for data cleaning and exploratory data analysis, MySQL for storing and managing the datasets, and SQL queries to analyze movie performance and identify useful patterns. I used Plotly to create interactive visualizations and Streamlit to develop a user-friendly dashboard with three main sections: Filters, Dashboard, and SQL Query Explorer. The Filters page allows users to filter movies by release year, language, and rating. The Dashboard displays key performance indicators and charts, while the SQL Query Explorer allows users to select predefined queries and view the results. Overall, this project demonstrates the complete data analytics workflow, from data cleaning and database management to analysis, visualization, and interactive dashboard development.
